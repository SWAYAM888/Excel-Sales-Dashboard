# 📊 Sales Dashboard in Microsoft Excel

## 📌 Project Overview

This project presents an interactive Sales Dashboard built using Microsoft Excel. The dashboard transforms raw sales data into meaningful business insights through dynamic visualizations, KPI tracking, and performance analysis.

The objective of this project is to help stakeholders monitor sales performance, identify growth opportunities, analyze profitability, and make data-driven decisions.

---

## 🎯 Key Objectives

- Analyze overall sales performance.
- Monitor profit trends and business growth.
- Identify top-performing products and regions.
- Compare yearly sales performance.
- Visualize geographical sales distribution.
- Enable interactive filtering for deeper analysis.
